# Audio

Procedural scores and effects are generated by `tools/build_audio.py`; impacts, dog voices and menu clicks are processed CC0 recordings (see `CREDITS.md`). 44.1 kHz Ogg Vorbis. Each course has a melodic stem and a synchronised drums stem for dynamic intensity, plus an ambience bed. Speed-reactive sled Foley and dog panting are seamless loops. Regenerate with Python, numpy and ffmpeg; sources are in `tools/audio_sources`. Runtime builds use the checked-in Ogg files.
