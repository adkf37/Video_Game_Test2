# Alpine Valley track

The playable track is generated by `godot/scripts/track/AlpineTrack.gd`. Its closed Catmull-Rom spline is sampled at 320 positions; arc lengths are used to place sixteen evenly spaced checkpoints.

## Editing

1. Change the control points in `_build_path()` to reshape the course.
2. Keep turns broad enough for a 25 m/s sled and separate neighboring paths by at least 30 m.
3. Keep elevation changes gentle; the current track ranges roughly from 0 to 6 m.
4. Preserve the 8 m trail half-width and broad recoverable shoulders unless handling is retuned.
5. Use the seeded scenery pass so art placement is reproducible.
6. Run `tests/drive_course.gd` after layout changes and manually check blind corners.

Road collision, scenery exclusion, checkpoint orientation, recovery poses and the minimap all derive from this same spline. There is no second hand-maintained minimap layout.

## Racing rules

Checkpoint zero is the start/finish line. The player starts behind it; the first forward crossing arms the lap. All other checkpoints must then be crossed in order before returning to zero. Three completed circuits finish the race.

Checkpoint volumes span 22 m, slightly wider than the 16 m trail, to allow forgiving corner exits. Crossing backward is ignored. Recovery restores the last validated checkpoint and adds three seconds.

## Art

Snow banks, trail-edge flags, pines and signs guide the route. Checkpoints remain invisible. The start banner sits above chase-camera height. Original models use shared low-poly mesh helpers in `scripts/art/AlpineArt.gd`; no paid or downloaded assets are required.
